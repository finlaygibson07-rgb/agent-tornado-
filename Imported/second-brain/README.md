# Your Second Brain — PARA System

This vault uses **PARA**: Projects, Areas, Resources, Archives.
The organizing question is never "what topic is this?" — it's **"what am I doing with this?"**

## The Four Folders

### 1. Projects
Anything with a **deadline** and a **defined finish line**. "Plan Japan trip," "Launch website," "Write Q3 report."
When a project ends, move its folder to Archives.

### 2. Areas
Ongoing responsibilities with **no end date** — you maintain a standard, you don't "finish" them.
"Health," "Finances," "Home," "Career." A project can live under an area (e.g. "Repaint kitchen" project under "Home" area).

### 3. Resources
Topics you're interested in for their own sake — reference material, research, things you might use later.
"Cooking," "Woodworking," "AI tools," "Book notes." Not tied to a project or responsibility.

### 4. Archives
Dead weight, kept for the record. Anything from the other three that's no longer active gets moved here as-is.
Don't reorganize on the way in — just drop it and move on.

## How to decide where something goes

Ask in order:
1. **Is it actionable right now, with an end date?** → Projects
2. **Is it a standard I maintain indefinitely?** → Areas
3. **Is it just useful/interesting to know?** → Resources
4. **Is it done/dead?** → Archives

If you're stuck, it's probably a Resource. Don't overthink it — PARA rewards fast filing, not perfect filing.

## Workflow

- **New note, unsure where it goes?** Drop it in `Inbox/`. Process the inbox weekly — move everything out.
- **Starting a project?** Duplicate `Templates/Project Template.md` into `1-Projects/`.
- **Weekly review** (10 min): empty the Inbox, check Projects for stale ones, archive anything finished.
- **Monthly review**: skim Areas — anything neglected? skim Archives — anything worth reviving?
